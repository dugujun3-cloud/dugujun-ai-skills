# 数据契约与证据等级

## 来源等级

| 等级 | 来源 | 可用于 |
| --- | --- | --- |
| A | 本人账号平台导出、平台后台截图、可验证原始表 | 账号基线、漏斗、涨粉和转化判断 |
| B | 平台公开页面、官方接口、用户授权的结构化 API | 公开表现、内容结构、竞品比较 |
| C | 用户手工记录、转述、局部截图 | 辅助判断，必须标明范围 |
| D | 模型从标题或内容推断 | 假设和编码，不得作为事实 |

不同等级的数据不要无说明地合并。竞品没有后台数据时，不推断真实曝光、点击率、收入、投流和粉丝画像。

## 标准作品字段

脚本自动识别常见中英文字段，并输出以下标准列：

```text
post_id,title,published_at,content_type,url,
impressions,views,likes,comments,saves,shares,followers_gain,
click_through_rate,watch_time_seconds,duration_seconds,engagements
```

未知字段默认不复制，避免携带个人信息。数字可以包含逗号、百分号、`万`、`w`、`k`；无法解析时记为空值并进入质量报告。

## 平台最低字段

### 小红书

- 最低：标题、发布时间、观看或曝光、点赞、评论、收藏。
- 推荐：分享、涨粉、封面点击率、内容形态、人均观看时长。
- 本人账号优先使用平台导出；公开笔记只能做作品表现和内容编码。

### 抖音

- 最低：标题、发布时间、播放、点赞、评论、分享。
- 推荐：时长、完播、平均播放时长、涨粉、主页访问、粉丝画像。
- 竞品的完播、涨粉和转化通常不可见，不要估算。

### B站

- 最低：标题、发布时间、播放、点赞、评论、收藏、投币、分享。
- 可将投币作为扩展字段保存到来源表；标准化脚本不会自动把投币混入收藏。

### 知乎

- 最低：标题、发布时间、阅读或观看、点赞、评论、收藏、分享。
- 知乎想法互动稀疏时，以已有平台基准判断，不要照搬其他平台的互动率标准。

## 多账号对比

- 使用相同平台、相同时间窗、相近内容数量和相同指标口径。
- 同时报样本量、中位数、P75、P90和零值率。
- 账号体量差异明显时优先比较率、分位和内容结构，不只比较总量。
- 无法确认投流、置顶、发布时间和账号阶段时，写入替代解释。

## 隐私和凭据

- 不收集手机号、邮箱、OpenID、Cookie、Token、密码或非必要用户级明细。
- API Key 只从环境变量读取，永不写入清单、报告、状态文件或终端回显。
- 若用户文件包含个人信息，只提取聚合指标和必要作品字段。
