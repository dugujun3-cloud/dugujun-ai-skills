# 工作流隔离规则

## 唯一职责

本 Skill 只解决“内容账号为什么表现成这样、下一阶段应验证什么”。它不负责直接生产或发布内容。

## 路由表

| 用户需求 | 主工作流 | 本 Skill 的位置 |
| --- | --- | --- |
| 分析本人或竞品账号 | `dugujun-account-analysis` | 主控 |
| 分析多账号差异 | `dugujun-account-analysis` | 主控 |
| 分析账号后制定实验 | `dugujun-account-analysis` | 主控，只到实验计划 |
| 写下一条小红书 | `dugujun-xhs-operating-workflow` | 只提供已完成的诊断输入 |
| 生成小红书图文 | `dugujun-xiaohongshu` | 不执行 |
| 处理新公众号文章和跨平台分发 | `dugujun-workflow-controller` | 不执行 |
| 分析知乎渠道历史数据 | `dugujun-zhihu-analytics` | 可读取其基准，账号分析仍由本 Skill 汇总 |
| 用户增长、会员、复购、生命周期 | `user-operations-playbook` | 不执行业务运营诊断 |
| 单篇内容审校 | 对应内容审校 Skill | 不执行 |

## 冲突处理

- “账号没流量，帮我写下一条”：先用本 Skill 完成最小诊断；诊断结束后明确移交生产工作流。两个阶段使用不同目录和状态文件。
- “分析这篇笔记”：只分析单篇内容时不触发账号工作流；只有用户要求账号级归因、历史比较或策略调整时触发。
- “分析用户运营账号”：若对象是内容账号，使用本 Skill；若问题是业务用户的拉新、激活、留存或复购，使用 `user-operations-playbook`。
- “继续”：只读取 `账号分析库/{platform}/{account_slug}/` 下最近一个未完成状态，不读取文章工作流或小红书笔记库的状态。

## 数据边界

- 原始知识库只读。
- 本 Skill 只写 `账号分析库/`。
- 不修改平台账号、浏览器草稿、内容资产和现有数据基准。
- 需要刷新全局小红书或知乎基准时，先移交对应平台 Skill；本次运行只引用刷新后的结果。
