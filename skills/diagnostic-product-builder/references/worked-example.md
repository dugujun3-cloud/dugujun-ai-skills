# 工作示例：职场路径诊断器

只读对照。新项目换领域词，不换顺序，不把本例的岗位结论拷走。

这是一套已交付产品的抽象记录，不是客户档案，不含本机路径。

## 这套产品证明了什么

| 抽象步骤 | 这套里的实例 |
|---|---|
| 锁一个决定 | 走不走、自己干不干。不保证 Offer / 一人公司做成 |
| 第一性三问 | 现在站哪 → 现实能走哪几条 → 想去哪合不合理 |
| 交付线（用户指定后锁死） | 当前状态 → 有哪些选择 → 在职场什么样 → 在职场怎么往上 → 理想是什么 → 不在职场的选择 → 第二曲线 → 诊断结果 |
| 两叉 | 在职场走「什么样 + 怎么往上」；不在职场先写理想再配第二曲线；主曲线只能一条 |
| 知识树漏过什么 | 上一版只抽公众号「交换三步」，漏了能力层和现实路径。这两块在知识库里，不在往期文章里 |
| 废止旧名 | 旧对外名进 `_archive/`，页上只留一个名字 |
| 9 维 × 4 态 | 交换、能力、缓冲、选择、在职场表现、去留、理想、不在职场、第二曲线 |
| 题干问事实 | 「交给公司的是什么」不是「该不该走」；「第一句通常说什么」不是「表达好不好」 |
| 总建议优先级 | 人已动但选择没写清 > 选择和理想都空 > 想离开但交货说不清 > 还在卖时间/做完事 > 万金油 > 心走了 > 第二曲线没货 > 各维能对上只钉一件 |
| 硬规则 | 缓冲 < 3 个月：走和全日制自己干冻结。说不出帮谁做什么：劝退 All in |
| 三层 | `1_网页工具/` 获客；`2_咨询交付框架/` 顾问用；`3_交付产品/` 会后给客户 |
| 改动纪律 | 用户点什么改什么。某一岗位样本不当默认结论 |

## 题干怎么从「判断」改成「可点」

| 判断（不能直接问） | 落成的题 |
|---|---|
| 他还在卖时间 | 这份工作，你主要交给公司的是什么 |
| 能力在哪一层 | 独立扛一件事，你通常能做到哪一步 |
| 现金流能不能走 | 没工资的话，房租吃饭还贷还能撑多久 |
| 路有没有写清 | 今天能走的选择，你写到哪了 |
| 价值有没有被看见 | 有人问「最近做成了什么」，你第一句通常说什么 |
| 会不会乱动 | 对眼下这份班，哪句更像你 |
| 理想清不清 | 「我想过的那种日子」现在能写到多清楚 |
| 外面有没有货 | 假如有人付钱请你帮忙，他请你帮的是哪一类 |
| 第二曲线到哪了 | 主业之外另一种可能，现在到哪了 |

新领域照此改：先有判断，再写成「上周发生了什么 / 写到哪了 / 第一句是什么」。

## 和邻居的差别

- 同仓库 `expertise-to-tool` 停在单文件工具。本例多了顾问 60 分钟、会前问卷、90 天手册、三层对拍。
- 知识百科网页用 0–3 分体检。本例禁止打分，用离散状态 + 优先级总建议。

## 不要从本例抄走的

- 任何一个具体岗位的现成结论
- 顾问自己的人生选项（考试、迁居、房产）
- 页上的出处和知识库目录名
- 已经废止的旧产品名
