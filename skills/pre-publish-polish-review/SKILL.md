# 发布前审校

读者发现一篇稿子敷衍的最后一个机会，就是发布前的语言质感。本 Skill 只做这一层：**保真、去 AI 味、排版、评分**。

## 核心边界

- **保真优先**：不改核心观点、案例、数字、结构顺序、立场
- **不新增素材**：不补编案例、公司名、数据、经历
- **不做二次创作**：除非用户明确说「重写」，否则只做表达性修改
- **不抹掉作者判断感**：保留锋利判断、短句、口语判断体
- 不为了「降 AI 味」牺牲信息密度
- 具体细节优先，但只使用原文或用户确认过的数字、案例和经历；宁可删掉空话，不编细节

## 三遍审校

### 第一遍：内容保真

对照原文逐段确认：观点没被改写、案例与数字没被替换、立场强度没被削弱、结构顺序没被调整。发现原文本身有问题时**只标记不修改**，交用户决定。

### 第二遍：降 AI 味

先出检测结论再改写。命中项逐条处理：能改则改，不能改须在审校结果里说明保留原因。

**AI 套话**（删除或替换）：在当今时代、随着科技的发展、在……背景下、值得注意的是、需要指出的是、综上所述、总而言之、让我们来看看、首先让我们、在实际应用中、从某种意义上说、毋庸置疑、不言而喻。

**平台黑话**（能删就删，能换成动作就换成动作）：赋能、打造、一站式、无缝、深度融合、显著提升、大幅增长、充分利用、有效降低。

**AI 句式**（连续出现降频）：

- 连续「不是 A 而是 B」：全文最多 1 次，超过优先改成直接肯定句
- 过度「既……又……不仅……而且……同时……并且……」
- 过度「从 A 到 B」排比

**定义腔**（少用）：「A 是 B」「所谓 A 即 B」「这才是关键」。优先改成行为、选择、代价和感受。

**自我反应式悬念**（非作者原文强意图则删除）：我愣了好一会儿、反复读了几遍、这句话戳到我了、我停下来想了三秒、久久不能平静。

**自我标榜式表达**（允许少量自然出现，密集就删）：很直白地说、很坦诚地讲、不夸张地说、说实话。

**六种「太」**：

| 症状 | 表现 |
| --- | --- |
| 结构太顺 | 连续「判断 → 三点 → 总结」过于工整 |
| 句子太满 | 每句话都像结论，没有人的停顿和取舍 |
| 套话太多 | 系统、闭环、赋能、价值、能力、流程、方法论等抽象词过密 |
| 过渡太模板 | 「核心在于」「本质上」「换句话说」「更重要的是」连续出现 |
| 解释太完整 | 每个观点都被讲成教科书，缺少真实判断的棱角 |
| 结尾太总结 | 用「总之／综上／最后」把全文重新概括一遍 |

**处理方式对照**：

| 类型 | 原句 | 改法 |
| --- | --- | --- |
| 名词化 | 进行能力建设 | 把这件事练出来 |
| 名词化 | 进行了优化 / 开展工作 | 优化了 / 开始做 |
| 书面词 | 具备 / 显著提升 / 充分利用 | 有 / 提升、涨了 / 用好 |
| 书面词 | 深入了解 / 进行操作 / 实施方案 / 切实可行 | 搞清楚 / 操作、做 / 按方案做 / 可行、靠谱 |
| 书面词 | 完成转化 | 让人买单 |
| 过度修饰 | 非常、显著、充分、有效、极其、大幅度 | 能不用就不用 |
| 被动句 | ……被完成了 | 改主动句 |

**允许保留（别误杀）**：每 3-5 段允许保留一句更直接的个人判断，但不能新增事实；作者原文里意图强烈的反应式表达保留并说明。

### 第三遍：细节排版

- 中文全角标点；引号统一
- 清理英文引号、半角逗号句号、乱码
- 段落适合手机阅读：长文约 3-5 行，社交平台更短
- 长句拆短，主流句长 15-25 字；为保留原意可放宽，但不连续长句
- 一段只说一件事，换话题就分段
- 删除无意义的「这就是／所以说／你会发现／值得注意的是」
- 大声读一遍；读起来像说明书、总结稿、课程稿，就继续改

## 第四步：标题一致性硬检查

对带标题的稿件执行：**标题做出的每个承诺，正文里必须有明确兑现的段落。**

- 标题说「错的是 A」，正文必须有对 A 的回答
- 标题带数字，正文必须出现该数字及其支撑
- 兑现不了的**改标题，不改正文去迁就标题**——正文观点是作者已确认的，标题是壳
- 无标题稿件跳过此步

## 第五步：审稿评分

三遍审校 + 标题一致性完成后给综合分：

| 分数 | 结论 |
| --- | --- |
| 90-100 | 可直接发布 |
| 80-89 | 小幅优化即可（列出优化项） |
| 70-79 | 需要修改（列出扣分项和修法，交用户决定） |
| < 70 | 建议重写（说明哪些层面不达标） |

评分口径：保真 30% / 表达 25% / 数据案例 25% / 结构 20%。标题一致性不达标一票扣到 80 以下。**输出必须带分数和扣分明细，不带分数的审校不算完成。**

## 平台差异

不同平台的读者预期不同，同一条内容要按平台调整颗粒度：

- **短图文 / 社交媒体**：标题、正文、话题标签、图内文案分别检查。caption 像跟朋友解释，不复述每张图；每张图只保留一个核心判断；图内文字短、狠、可扫读；必须有收藏锚点（清单、步骤、公式、对比、问题框至少一种）；标签 3-5 个且精准，不堆泛标签
- **长文 / 图文平台**：开头前 2-3 句要直接回答问题，不像万能模板；保留口语判断体，不做论文式三段论
- **正式文章**：先过内容质量审查，再过本 Skill 的三遍审校

## 机器检查

人眼会漏，机器不会。发布前跑一遍：

```bash
rg -n '“|”|‘|’|"' path/to/file.md          # 引号统一
rg -n '——' path/to/file.md                   # 破折号
rg -n '在当今|随着科技|背景下|值得注意的是|需要指出的是|综上所述|总而言之|让我们|首先让我们|接下来让我们|在实际应用中|从某种意义上说|毋庸置疑|不言而喻|不仅.*而且|显著提升|大幅增长|充分利用|有效降低|赋能|打造|一站式|无缝|深度融合' path/to/file.md
rg -n '[一-龥][,:?!]' path/to/file.md        # 中文后半角标点
rg -n '愣了好一会儿|反复读了几遍|戳到我了|停下来想|久久不能平静' path/to/file.md
rg -n '不是.{1,15}而是' path/to/file.md
```

命中不等于一定错误，但**必须逐条处理**：能改就改，不能改就在审校结果里说明为什么保留。

**硬闸门**：英文引号、破折号、乱码、中文后半角标点，默认必须清掉；AI 套话和自我反应式悬念，默认必须删除或改写；「不是……而是」出现 2 次以上，必须降到 1 次以内；如果是图内文案、社交平台 caption 或开头段，命中项优先级最高。

## 输出格式

```text
审校结果：
- 审稿评分：XX / 100（90+ 可发布 / 80-89 小幅优化 / 70-79 需修改 / <70 重写）
- 内容保真：通过 / 需处理
- 标题一致性：通过 / 不达标（兑现不了改标题）
- AI 味风险：...
- 标点排版：...
- 机器检查：通过 / 仍有保留项
- 逐条处理记录：命中项 → 改法 或 保留理由
```

## 保底机制

时间不足或稿件过长时，至少审校：标题、开头段、结尾、话题标签。如果修订会明显改变作者原文风格，**停止大改**，只输出问题清单和局部建议。保底版也必须是可发布草稿，不能留下半成品。
