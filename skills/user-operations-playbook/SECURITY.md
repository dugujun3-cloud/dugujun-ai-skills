# Security

Do not attach real customer records, credentials, private case libraries, or internal company data to public issues.

When reporting a problem, provide a minimal synthetic reproduction. Remove local paths, account identifiers, tokens, links with private query parameters, and business data before sharing.

The Skill provides operating analysis, not authorization to access CRM systems, send messages, change membership balances, or publish customer data. External actions require separately configured tools and explicit user approval.
