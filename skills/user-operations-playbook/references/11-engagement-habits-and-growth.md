# 活跃、参与、习惯与用户成长

## 适用问题与边界

用于处理用户已完成首次价值，但没有持续参与、核心行为频次下降、任务体系空转或成长机制无效的问题，例如：

- DAU、MAU 或打开次数波动，但不知道是否影响业务价值。
- 用户会签到、领积分，却不完成核心使用、内容贡献或交易行为。
- 想做任务、等级、徽章、积分或游戏化，却不知道该激励什么行为。
- 活跃用户很多，留存、转化、内容质量或贡献没有同步改善。
- 用户完成一次核心行为后，没有形成重复使用或稳定参与。
- 低频业务被要求追日活，运营只能靠消息和补贴制造访问。

本模块区分四个概念：

```text
活跃 = 在定义窗口内完成有效行为
参与 = 行为的深度、广度、质量或互动程度
习惯 = 在真实需求或稳定触发下重复完成核心行为
成长 = 用户能力、关系或贡献沿可解释路径提升
```

边界：

- 打开、停留、签到、点击和消息阅读不是天然的有效活跃，只能作为过程指标。
- 相关行为与高留存同时出现，不代表强推该行为一定提升留存。
- 游戏化不能创造产品不存在的持续价值，也不能替代供给、体验或服务修复。
- 低频交易、季节性、一次性任务和长周期服务应按“需求机会、里程碑或应完成事件”衡量，不强行追 DAU。
- 会员等级、积分负债和权益经济性由会员模块负责；本模块只判断成长机制是否驱动目标行为。

## 最少输入

| 输入 | 最低要求 |
|---|---|
| 核心价值行为 | 用户重复完成什么行为才能持续获得价值 |
| 自然机会与周期 | 用户多久通常出现一次真实需求或使用机会 |
| 有效活跃口径 | 行为、窗口、去重和合格用户范围 |
| 行为数据 | 用户级事件、时间和至少一个质量或结果字段 |
| 分群 | 生命周期、渠道、价值层或使用深度之一 |
| 当前机制 | 内容、任务、提醒、积分、等级、社交或人工服务 |
| 业务结果 | 留存、交易、贡献、供给质量或服务采用之一 |
| 约束与风险 | 频控、奖励成本、内容/服务供给、作弊、投诉 |

若只有总 DAU/MAU，没有用户级行为或 Cohort，先做指标口径审计，不能直接设计成长体系。

## 诊断步骤

### 1. 定义“有效活跃”

用业务结果反推行为：用户完成什么动作，才能获得价值或推动价值产生？

把事件分为：

- 核心价值行为：直接交付或消费核心价值。
- 关键前置行为：为核心价值做准备。
- 贡献行为：为其他用户或平台创造价值。
- 表面行为：打开、签到、浏览等，仅说明到访。
- 风险行为：刷任务、无效互动、低质内容或异常交易。

只把前两类或有明确业务依据的贡献行为纳入有效活跃。表面行为可用于诊断，不作为最终目标。

### 2. 拆解活跃结构

不要只看一个总量。至少拆解：

```text
活跃用户 = 新激活用户 + 连续活跃用户 + 回流用户 - 当期沉默用户
```

按 Cohort、生命周期、渠道或价值层比较活跃人数、频次、有效行为占比和质量。判断增长来自真实持续参与，还是新增堆积、活动回流或口径变化。

### 3. 建立行为阶梯

按价值递进而不是页面访问量排列：

```text
首次完成 → 再次完成 → 稳定重复 → 深度使用/贡献 → 自主回访或共创
```

每一级明确进入事件、退出事件、期望停留周期和下一步。若相邻层没有不同策略，不必人为拆层。

### 4. 找稳定触发与阻塞

检查“触发 → 行动 → 反馈 → 再次使用理由”：

- 触发是否来自真实需求、业务事件或用户自定计划，而非只靠群发。
- 行动是否足够清晰，路径、能力、时间和供给是否允许完成。
- 反馈是否让用户看见结果、进度、能力或关系积累。
- 用户是否有明确的下一次需求时点或未完成目标。

外部提醒只能帮助用户记起已有价值；如果提醒停止后行为立即消失，说明习惯或持续价值尚未建立。

### 5. 验证关键行为候选

比较完成与未完成候选行为的同窗后续留存、质量和贡献，同时控制渠道、进入时期、用户类型和使用机会。把候选行为记为相关证据，再用降低门槛、结果反馈或引导实验验证可干预性。

### 6. 审计现有任务与成长机制

逐项检查：目标行为、用户价值、奖励成本、完成难度、作弊空间、退出规则和下游结果。删除只制造签到、点击、刷屏或无效内容的任务。

### 7. 选择一个最小机制实验

优先解决一个阻塞：看不懂下一步、行动成本高、反馈缺失、进度不可见、内容/供给不匹配或触发时机错误。一次不要同时上线任务、积分、等级和社群四套体系。

## 判断规则

| 信号 | 判断 | 下一步 |
|---|---|---|
| DAU 上升、有效行为率下降 | 表面访问或新增结构可能稀释质量 | 拆新增/连续/回流并检查活动来源 |
| 签到、积分领取高，核心行为不变 | 奖励与价值行为脱节 | 停止扩大签到奖励，重设任务目标 |
| 活跃频次提升但投诉、低质内容或退款上升 | 机制可能诱导错误行为 | 收紧质量门槛并检查单位经济性 |
| 某行为与留存高度相关 | 它是关键行为候选 | 控制选择偏差并做可干预实验 |
| 只在提醒当天活跃 | 外部触发有效，内在需求或持续价值不足 | 连接业务事件和用户自定计划 |
| 新用户活跃、老用户下降 | 激活改善不等于成熟用户价值稳定 | 按生命周期分别定位供给和价值问题 |
| 活跃周期符合真实需求但日活低 | 可能是指标选错，不一定是运营失败 | 改看机会留存、里程碑和周期完成率 |
| 成长等级人数上升但高价值行为不升 | 升级规则与业务价值脱节 | 调整成长值来源或停止该等级机制 |

任何固定频次、等级数量、积分比例或阈值都必须来自本业务分布、资源能力和实验，不使用通用行业数字。

## 策略机制

### 1. 价值驱动的重复路径

把一次价值延伸为下一次真实使用理由：结果跟踪、周期提醒、进度延续、未完成目标、后续服务或相关内容。提醒内容说明“为什么现在值得回来”，而非只说“你很久没来了”。

### 2. 触发机制

按优先级选择：

1. 用户内部需求或自定计划。
2. 订单、账单、内容更新、项目节点等业务事件。
3. 社交或协作事件。
4. 经许可的外部消息提醒。

越依赖第 4 类，越要检查疲劳、退订和提醒停止后的真实留存。

### 3. 行动减阻与反馈

- 让用户从触发点直接回到未完成或最相关的位置。
- 显示完成结果、进度、影响或下一步，而非只给“成功”提示。
- 对复杂行为提供清单、模板、示例或人工帮助。
- 对失败行为保留恢复路径，不用重复惩罚制造挫败。

### 4. 任务机制

任务只奖励目标行为或必要前置行为。任务卡必须包含：适用人群、行为、完成标准、用户收益、业务收益、奖励成本、有效期、次数上限、反作弊和退出条件。

短期任务用于帮助用户跨过学习或行动门槛；当行为稳定后逐步减少外部奖励，检查是否仍会自然发生。

### 5. 成长机制

适用于用户确实存在能力、关系、贡献或使用深度递进的业务。设计顺序：

```text
成长目标 → 高价值行为 → 可解释进度 → 阶段反馈 → 对应能力/服务/权限 → 升降级与退出
```

成长值不能只奖励消费，也不能让无效互动取代真实贡献。若权益没有差异或履约能力不足，不先画等级。

### 6. 内容、服务与共创

内容用于解决当前阶段的真实问题，服务用于降低复杂任务成本，共创用于让合适的高参与用户贡献反馈、内容或协作。三者均需明确质量标准、审核容量和负反馈机制。

### 7. 低频业务的机会运营

围绕事件和需求窗口运营：购买周期、保养/续约节点、项目里程碑、家庭阶段或服务到期。非需求期提供有用的信息或服务即可，不靠无关任务制造高频。

## 指标与口径

```text
有效活跃率 = 窗口内完成有效行为的用户数 / 合格用户数
有效行为占比 = 有效行为次数 / 全部被计入的活跃行为次数
重复行为率 = 完成至少两次核心行为的用户数 / 完成首次核心行为的用户数
机会完成率 = 在真实需求机会出现后完成目标行为的用户数 / 出现该机会的合格用户数
活跃迁移率 = 从当前行为层进入下一行为层的用户数 / 当前行为层用户数
任务增量完成率 = 实验组目标行为率 - 可比对照组目标行为率
单位增量成本 = 增量奖励与运营成本 / 增量有效行为用户数
```

主要指标选有效活跃率、重复行为率、机会完成率或迁移率之一。诊断指标可用频次分布、完成耗时、深度、内容/服务质量和触发响应。

护栏至少包括：次期留存、转化或贡献、投诉/退订、低质内容率、作弊率、奖励成本、服务容量、退款/取消。不要用平均停留时长代替价值，除非业务能够证明时长本身有价值。

## 护栏与停止条件

以下情况停止、回滚或降级机制：

- 有效行为没有改善，只增加打开、签到、点击或消息响应。
- 奖励停止后行为完全消失，且增量贡献不能覆盖持续成本。
- 出现刷任务、虚假互动、低质供给、骚扰其他用户或异常交易。
- 活跃提升但留存、转化、贡献、满意度或供给质量恶化。
- 触达频率导致投诉、退订、卸载或渠道限制达到预设阈值。
- 成长等级承诺的权益无法履约，或升级规则不透明、不可解释。
- 用户已经完成目标、退出机制、退订或不再有真实需求机会。
- 核心问题来自产品价值、供给不足或服务故障，任务和激励无法修复。

放量条件：目标行为有可比增量、下期仍保持、护栏稳定、单位增量成本可接受、供给和服务容量可扩展。

## 输出契约

1. **有效活跃定义卡**：合格用户、核心行为、窗口、机会口径、去重与业务理由。
2. **活跃结构表**：新激活、连续、回流、沉默及各自有效行为和质量。
3. **行为阶梯**：每层事件、迁移条件、阻塞、下一步和退出规则。
4. **习惯回路诊断**：触发、行动、反馈、再次使用理由和证据缺口。
5. **任务/成长机制审计**：目标行为、用户价值、奖励、成本、风险、保留/调整/删除判断。
6. **策略单元**：人群、障碍、目标行为、机制、触发、渠道、频率、退出条件。
7. **实验与指标卡**：唯一变量、对照、周期、主要指标、护栏、停止和放量条件。
8. **7 天验证与 30 天机制**：最小实验、埋点/规则/供给建设及负责人。

结论中必须回答：当前缺的是持续价值、正确触发、行动能力、结果反馈、成长路径，还是指标口径。
