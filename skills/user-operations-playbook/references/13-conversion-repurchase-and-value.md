# 转化、复购与用户价值

用于回答“用户为什么不买、如何提升首购或关键转化、为什么买过却不再买、怎样提高客单与贡献”。本模块处理从意向到交易、从首购到再次购买的运营问题；LTV、增量 ROI 和实验统计口径分别与 `06-metrics-ltv-and-roi.md`、`05-strategy-and-experiments.md` 联动。

## 1. 触发问题与边界

出现以下问题时进入本模块：

- 到达、咨询、试用、加购或提交订单的人很多，完成支付或关键承诺的人少。
- 首购依赖补贴，优惠结束后转化消失，或退款、拒收、投诉同步上升。
- 用户已经购买，但没有在合理需求周期内复购、续订或增购。
- 想提升客单、连带、购买频次或贡献毛利，不知道应优先改人群、商品、价格还是触达。
- 表面 GMV 增长，但无法判断来自自然需求、提前透支、价格下降还是运营增量。

本模块不能替代以下工作：

- 产品没有解决真实需求、价格严重失配、库存不足、支付故障、履约失败、服务能力不足时，先修业务根因，不用更多触达掩盖。
- 不凭运营数据决定商品安全、医疗效果、金融适当性或其他专业合规结论。
- 没有对照或反事实时，只能报告描述性变化，不把总成交写成运营增量。
- 不使用虚假稀缺、伪造评价、隐藏费用、默认勾选、阻碍退款等暗黑模式。

## 2. 最少输入

缺少以下输入时先输出采集表，不直接给确定性放量方案：

```text
业务与目标：产品/服务、目标转化、价值与毛利口径、决策期限
目标用户：生命周期、需求或任务、历史购买状态、触达许可
交易链路：关键步骤、事件定义、顺序、观察窗口、异常状态
商品与供给：价格、组合、库存、交付周期、退款/退订/取消规则
历史数据：匿名用户ID、事件时间、订单、金额、退款、成本、渠道/活动
复购信息：通常使用或消耗周期、上次购买、品类/规格、后续需求信号
约束：预算、优惠成本、毛利底线、履约产能、渠道频控、合规限制
```

长决策周期业务可以用“有效咨询、方案确认、合同签署”等关键承诺替代即时支付，但必须说明它与最终价值的关系。

## 3. 先诊断问题属于哪一层

按顺序排查，不要把所有问题归结为“优惠不够大”：

1. **人群与需求**：用户是否有当前需求、支付能力和决策权，入口承诺是否吸引错人。
2. **价值理解**：用户是否理解产品解决什么问题、适合谁、为什么现在行动。
3. **信任与风险**：证据是否可核验，试用、售后、交付和退款预期是否清楚。
4. **选择成本**：商品、套餐、规格、权益或步骤是否过多，用户是否知道下一步。
5. **价格与单位经济性**：价格、促销、组合和支付方式是否与价值和毛利相容。
6. **流程与技术**：页面、表单、支付、库存、客服、销售跟进或跨端链路是否中断。
7. **复购时机**：用户的需求周期是否真的到来，是否出现补货、用尽、成果进阶或续期信号。
8. **产品与体验**：首次消费是否获得价值，质量、使用难度、履约或服务问题是否阻止再次购买。
9. **测量与归因**：重复订单、取消退款、提前囤货、自然回购和活动归因是否处理正确。

先写“现象—证据—候选根因—还需验证”，不要看到漏斗下降就直接开券。

## 4. 建立转化与复购状态链

按业务定义状态，不强制套用固定电商步骤：

```text
有效到达 → 需求表达/关键浏览 → 方案或商品选择 → 承诺动作
→ 下单/签约 → 有效支付 → 成功履约 → 首次价值确认
→ 下一需求信号 → 再次购买/续订/增购 → 再次价值确认
```

每个状态写清：进入事件、退出事件、超时、取消/退款、重复事件、观察窗和数据源。至少输出：

| 步骤 | 可进入人数 | 完成人数 | 步骤转化率 | 中位耗时 | 退出/异常 | 差异人群 | 可干预假设 |
|---|---:|---:|---:|---:|---:|---|---|

比较漏斗时统一 Cohort、入口和成熟窗口。若数据无法串联到匿名用户层，不生成伪精确路径。

## 5. 转化决策规则

### 5.1 先定最大可干预损失点

优先处理同时满足以下条件的节点：

- 损失人数或贡献规模大。
- 靠近实际价值，不只是点击等虚荣指标。
- 有行为、访谈、客服或技术证据支持根因。
- 团队能在当前周期改变一个主要机制。
- 改变后不会突破毛利、履约、投诉或合规护栏。

高流失但不可干预的节点不排第一；低流失但对高价值人群影响大的节点可单独处理。

### 5.2 用根因选择机制

| 主要根因 | 优先机制 | 不应先做 |
|---|---|---|
| 需求或人群不匹配 | 收窄入口、人群与主张，补资格判断 | 加大普惠补贴 |
| 价值不清 | 场景化说明、对比选择、演示、试用或结果路径 | 堆砌卖点和倒计时 |
| 信任不足 | 可核验证据、透明承诺、售后与履约说明 | 伪造评价或权威背书 |
| 选择困难 | 减少选项、推荐规则、默认但可撤销的辅助选择 | 增加更多套餐 |
| 流程阻塞 | 修页面、支付、表单、库存、交接和响应 SLA | 用消息催促用户重试 |
| 价格或现金流阻力 | 价值分层、组合、试用、分期或透明优惠实验 | 无毛利测算的全面降价 |
| 时机未到 | 识别需求信号和合理窗口，提供提醒与保存 | 高频催单 |
| 首次体验差 | 产品、教学、服务、交付和售后补救 | 直接推复购券 |

策略单元必须写成：

```text
目标人群 + 所处状态 + 已证实障碍 + 目标行为 + 价值机制
+ 触发时机 + 渠道/责任人 + 频控 + 主要指标 + 护栏 + 退出条件
```

## 6. 复购、续订与增购机制

### 6.1 先识别真实需求周期

优先使用业务信号，而非固定“购买后第 N 天”群发：

- 补货型：预计消耗、库存、使用频次和上次购买规格。
- 周期服务型：服务到期、权益消耗、使用进度和续期窗口。
- 成果进阶型：完成上一阶段、技能或任务后出现的新需求。
- 事件触发型：季节、生命周期、家庭/企业事件或场景变化。
- 跨品类型：已完成核心价值后出现的互补需求，不等于无关搭售。

数据不足时先用历史订单间隔分布和访谈形成假设；不得把全体平均间隔当成每个用户的确定周期。

### 6.2 按阻碍选择复购动作

| 阻碍 | 机制 | 验证重点 |
|---|---|---|
| 周期未到 | 保存、提醒、订阅或补货预测 | 是否减少打扰且不透支未来订单 |
| 忘记或路径麻烦 | 一键复购、历史方案、库存/到期提醒 | 完成率与取消退款 |
| 未获得首次价值 | 使用辅导、服务补救、问题闭环 | 首次价值和满意度先恢复 |
| 需求升级 | 进阶内容、升级方案、互补组合 | 增量贡献而非订单迁移 |
| 价格敏感 | 价值说明、规格/组合选择、定向权益 | 贡献毛利与优惠依赖 |
| 供给或履约不稳 | 修库存、交付和服务承诺 | 履约成功后再扩触达 |
| 信任下降 | 1v1回访、透明解释、售后补救 | 投诉、退订和关系修复 |

增购和交叉销售必须与已知需求相关，并允许用户拒绝。用高客单替代原低客单不等于新增价值，需检查品类迁移和毛利变化。

## 7. 用户价值与单位经济性

至少同时看数量、质量和贡献：

- **有效转化率** = 通过取消、退款、异常规则的目标转化人数 ÷ 可转化人数。
- **首购转化率** = 有效首购人数 ÷ 对应可首购用户数。
- **复购率** = 在指定观察窗内再次有效购买的用户数 ÷ 已成熟且具备复购机会的首购用户数。
- **购买频次**：观察窗内每位有效购买用户的有效订单次数。
- **客单与件单/连带**：须同时检查折扣、退款和商品结构。
- **贡献毛利** = 收入 - 商品/服务、优惠、渠道、支付、履约、售后等可归属成本。
- **回收周期**：累计贡献覆盖获客与增量投入所需时间。
- **Cohort LTV**：统一进入时点和观察窗后的累计贡献，具体口径见 `06-metrics-ltv-and-roi.md`。

复购率必须说明分母是否已进入可复购窗口。低频业务优先看需求事件、有效线索、转介绍和长期贡献，不为提高频次制造无效消费。

## 8. 验证与决策

一次实验只改变一个主要机制，例如“为完成首次价值但未下单的人增加透明试用说明”。实验按 `05-strategy-and-experiments.md` 建卡，并至少包含：

- 主要指标：有效转化、有效复购或贡献毛利，按决策只选一个。
- 领先指标：关键步骤完成、价值确认、咨询响应等。
- 护栏：退款、取消、拒收、投诉、退订、优惠成本、履约时效和客服负荷。
- 反事实：随机对照、保留组、分阶段或可比 Cohort；无法构造时降低结论强度。
- 成熟窗口：覆盖支付、履约、退款和复购机会，不在结果未成熟时放量。

决策规则：

| 主要结果 | 护栏 | 决策 |
|---|---|---|
| 改善且贡献为正 | 稳定 | 小步扩大并监控边际成本与人群漂移 |
| 改善 | 退款、投诉、履约或毛利恶化 | 不放量，先修机制或收窄人群 |
| 无法判断 | 稳定 | 补样本、延长成熟窗或改进测量 |
| 无改善 | 稳定 | 停止该机制，回到根因树 |
| 无改善 | 护栏恶化 | 立即停止并处理用户影响 |

## 9. 护栏与停止条件

### 必备护栏

- 价格、库存、到货、权益、自动续费、退款和退出规则透明。
- 用户完成目标、拒绝、退订、投诉、退款或进入人工服务后，停止不相关序列。
- 优惠不得诱导不适配人群，不以成瘾、恐惧或未成年人弱点促成交易。
- 促销必须测算完整成本和履约能力；敏感品类先做法律与业务审查。
- 订单、评价、稀缺、库存、倒计时和案例均不得伪造。

### 立即停止或降级

- 退款、拒收、投诉、退订、欺诈或履约失败越过业务预设红线。
- 贡献毛利转负、回收期超出现金流约束，或边际成本持续恶化。
- 技术、库存、客服或交付无法承接新增订单。
- 数据串联、分流或口径失效，无法知道结果来自谁和何时成熟。
- 主要指标只在补贴期改善，撤除补贴后消失且无长期价值证据。

阈值必须来自本业务基线、合规要求和产能约束；缺少阈值时要求负责人先确认，不生成行业数字。

## 10. 输出契约

转化或复购任务默认输出：

1. 决策问题、业务目标与适用边界。
2. 最少输入完成度和不可回答项。
3. 转化—履约—首次价值—复购状态链与最大损失点。
4. “现象—证据—根因—验证”诊断表。
5. 人群化策略单元和触达/服务序列。
6. 指标字典、Cohort/漏斗口径与贡献毛利口径。
7. 一个最小实验及放大、调整、停止规则。
8. 退款、投诉、频控、履约、毛利和合规护栏。
9. 7 天修复动作、30 天机制建设和责任人。

数据不足时，输出最小采集表、可验证假设和多个有取舍的方案；不输出虚构的转化率、复购周期、预算、优惠力度或增长承诺。
