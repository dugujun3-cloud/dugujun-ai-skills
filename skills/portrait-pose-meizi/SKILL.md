# 人像美姿提示词

摄影美姿转写到 AI 生图。人物要好看，先破面。口诀：转、弯、顺、露。

方法细则、公式、试用姿态、景别与松紧：读 [`references/pose-method.md`](references/pose-method.md)。写具体朝向/弯曲/落点/线条、做诊断、或用户问为什么时必读。不要另造理论。

## 硬闸

- 只处理成年角色姿势。
- 不写低俗、挑逗、性化姿势指令。
- 不把「破面」写成扭曲、断肢、反关节。
- 不扩成妆造企划、角色五官设计或视频分镜。
- 默认中文。用户要求英文时再给英文姿势句。
- 默认只输出文字。只有用户明确要求生图时才生图。

## 先判任务（只选一种主路径）

新写姿势 / 改已有提示词 / 诊断为什么难看 / 同一人物出多组姿态。

## 工作流

1. **先锁姿态骨架，不要先堆风格词。** 骨架必须包含：怎么站坐或趴蹲躺 + 朝哪里 + 一个具体动作。四条公式是四个调整入口，不必每次全部塞进去。先判断当前最该改朝向、弯曲、连接，还是遮挡，只改对应一句。
2. **检查四个入口，缺什么补什么，已成立的不要重复堆砌：**
   - 转：头、上身、腿三个面是否全朝镜头
   - 弯：是否像一根直杆（转脸≠歪头）
   - 顺：手腕、脚尖是否突然折角
   - 露：手有没有落点，手指是否可被理解
3. **再按用途补景别和松紧。** 需要腿长就避免膝盖正对镜头，并考虑全身。中景不一定能看到脚。
4. **禁止**单独使用「自然一点」「松弛一点」「好看一点」「姿态优美」。除非同时给出具体朝向、弯曲、手部落点和线条接续。
5. 用户没有提供人物、服装、场景时，只交付可插入的姿势片段。用户要完整生图提示词时，把姿势段嵌进完整中文 Prompt；不要改写用户已锁定的脸、妆、服、光。
6. 用户未要求分析时，不要输出长篇理论。默认给可复制的提示词。用户问为什么时，用四字口诀解释改了哪一项。

## 输出（只选一种，除非用户要对比）

- **A.** 姿势短句（可直接插入现有提示词）
- **B.** 完整中文生图提示词（姿势段单独成句，不要和脸、光、服装缠在一起）
- **C.** 诊断 + 修改前后对照

### 示例（A）

用户：帮我写一个窗边坐姿，要显腿长，手别消失。

输出：

侧坐窗边，身体侧转，脸转向镜头，双腿斜伸，脚尖顺着腿线延伸，手轻搭膝上，手指可见。
