# 证据卡与连续追问

## 项目证据卡

每个核心项目填写一张，缺失项保留为空，不用形容词代替事实。

| 字段 | 内容 |
| --- | --- |
| 业务问题与基线 | 为什么要做，开始时是什么状态 |
| 目标来源 | 谁提出，为什么是这个目标 |
| 指标口径 | 公式、统计周期、样本和对照口径 |
| 本人职责边界 | 决策、执行、协同分别做到哪一步 |
| 核心判断 | 从哪些事实得出什么判断 |
| 关键动作 | 先后顺序、资源、工具和协作方 |
| 取舍 | 没做什么，为什么 |
| 结果 | 相对目标、基线或对照组的变化 |
| 归因与复验 | 如何证明结果与动作有关，是否重复验证 |
| 负面结果 | 成本、副作用、未完成部分 |
| 可核验来源 | 报表、复盘、负责人或公开信息 |
| 公开边界 | 哪些数字或名称不能公开 |

## 五层追问树

对每个核心项目依次追问，直到口径、归因和个人贡献说清。

1. 目标：指标是谁定的，基线、目标量级和周期是什么？
2. 判断：为什么优先解决这个问题，排除了哪些假设？
3. 个人贡献：哪些决策和动作由你完成，团队分别做了什么？
4. 落地：资源不足、跨部门阻力和异常情况怎么处理？
5. 结果：是否达到目标，怎么归因、复验，代价是什么？

如果回答仍停留在方法论，继续问具体日期、对象、动作、样本、口径和决策节点。不要逼迫候选人公开保密信息。

## 失败案例卡

- 原定目标与预期。
- 实际结果及差距。
- 最早出现的异常信号。
- 当时为什么没有更早发现。
- 根因与本人应承担的责任。
- 止损时点、动作和沉没成本处理。
- 修改了什么机制。
- 后续如何验证修改有效。

质检重点：不甩锅、不把失败包装成成功、不只讲感悟、不回避何时应该停止。

## 显著标签触发题

从简历和自我介绍中找出区别于普通候选人的标签，例如空窗、创业、跨行业、管理跨度、AI实践或频繁转换。每个标签自动生成：

1. 招聘方最担心什么。
2. 哪些事实能证明它是资产而非风险。
3. 最尖锐的三轮追问。
4. 一句边界清楚的结论。
5. 与目标岗位的具体关系。

AI实践类标签至少回答：真实产物、改造了哪段流程、产生什么结果、限制和风险、入职后最先验证的场景。不要只罗列工具。
