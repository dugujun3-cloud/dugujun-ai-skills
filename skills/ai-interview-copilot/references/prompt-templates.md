# 提示词模板

## 事实底稿

```text
先不要写面试答案。把我提供的经历整理成事实底稿和项目证据卡，逐项标记：已确认、待确认、不可公开。重点检查目标来源、指标口径、本人职责、关键判断、动作、资源依赖、结果、归因和负面结果。不得补写任何数字。
```

## 岗位拆解

```text
请从招聘方视角拆解以下JD。不要改写JD，要回答：业务为什么招人、入职后最需要解决的3—5个问题、核心指标、硬门槛、加分项、容易淘汰的风险点。未知信息请标记，不要编造。
```

## 问题预测

```text
结合JD与我的真实经历预测问题。70%的准备精力放在过往经历和风险点，30%放在JD、业务和其他变量。每个问题说明面试官的真实目的、需要的证据和可能追问。不要先生成答案。
```

## 硬门槛审计

```text
把JD硬门槛逐项分为：已证明、相邻能力、明确不具备。任何明确不具备项单独评估是否可能一票否决，不要用综合匹配分稀释。为每个缺口生成诚实回答：能力边界、实际做过的相邻工作、协作边界、可验证案例、补强计划。
```

## 连续追问树

```text
围绕这个项目连续追问五层：指标谁定、目标与口径、本人贡献、决策依据与取舍、结果归因与复验。一次只问一题；如果我的回答仍抽象，继续要求具体动作、对象、周期或口径，不要替我补事实。
```

## 一问一答模拟

```text
你是该岗位面试官。一次只问一个问题，根据我的回答继续追问。不要提前给标准答案。每题结束后在内部记录证据缺口，满5题后再统一反馈。
```

## 风险叙事压力测试

```text
围绕我的离职、空窗、创业或转型经历连续追问三轮，检查时间线、因果、回归职场动机和稳定性是否一致。不要因为空窗本身直接扣分，也不要接受空泛的成长叙事。最后指出矛盾、过度解释和缺少证据的位置。
```

## 打断训练

```text
模拟真实业务面。随机在我铺垫过长或偏题时打断，要求我先确认真正问题，再用一句结论和一个证据恢复。分别训练15秒、60秒和180秒版本，并检查背稿感、自问自答和模糊词。
```

## 回答优化

```text
保留事实，不新增数据。按「结论、必要背景、核心判断、行动、结果、复用方法、岗位关联」优化成口语版。指出删掉了哪些无效铺垫，并列出面试官最可能的两个追问。
```

## 场景题

```text
不要直接给方案。先提出诊断假设，再说明需要哪些数据验证，如何判断根因，如何小范围测试，如何分阶段铺开，最后补指标和风险。
```

## 面试复盘

```text
只根据逐字稿复盘。还原全部问题和回答，区分事实、推断、未知。识别决定性问题并说明权重依据。通过可能性只给区间、置信度和不可控变量，不把客套结束语当作通过信号。
```

## 跨场校准

```text
比较这些面试时，以“涉及场次数”统计问题和失败模式，不用关键词出现次数。记录每场的轮次、预测区间、证据强度、真实结果、反馈、曾高估或低估的信号，并区分可控与不可控变量。
```

## 反问设计

```text
分别为HR面、业务面和终面设计反问。每个问题写明想验证的假设、不同回答意味着什么、如何回写下一轮准备。避免重复问官网可查信息，也不要跨轮次机械重复同一问题。
```

## 双模型复核

```text
你是独立复核者。只看下面的脱敏材料，不参考任何其他模型的结论。分别列出事实、推断、未知变量、可能反证和概率区间。任何结论都要指出对应证据；证据不足时直接说不知道。
```
