# 面试回答评分标准

每项0—5分。分数用于定位训练优先级，不代表录用概率。

| 维度 | 0—1分 | 2—3分 | 4—5分 |
| --- | --- | --- | --- |
| 直接性 | 没回答问题 | 回答但结论后置 | 15秒内给出明确结论 |
| 相关性 | 与岗位无关 | 有关联但泛 | 紧扣岗位目标和场景 |
| 真实性 | 无证据或疑似编造 | 有事实但边界模糊 | 事实、角色、数据可追溯 |
| 决策逻辑 | 只讲做了什么 | 有原因但不完整 | 讲清判断、取舍和验证 |
| 行动细节 | 只有方法论 | 有步骤但缺落地 | 动作、资源、协作清楚 |
| 结果证据 | 无结果 | 有结果但口径不清 | 数据、周期、对照清楚 |
| 迁移价值 | 只适用于旧项目 | 能解释部分迁移 | 明确说明如何服务新岗位 |
| 表达效率 | 铺垫、重复、模糊 | 基本清楚 | 结论先行、层次稳定、可追问 |
| 口语自然度 | 明显背稿或自问自答 | 基本自然但模板感强 | 可随追问改变长度与结构 |
| 归因边界 | 把团队结果全算给自己 | 能说明部分分工 | 本人、团队、外部变量边界清楚 |
| 压力恢复 | 被打断后抢话或失焦 | 能回到问题但仍冗长 | 确认问题后用结论和证据恢复 |

## 硬门槛先行

评分前先检查硬门槛。把每项标成已证明、相邻能力或明确不具备。明确不具备可能是一票否决项，不能用其他维度的高分抵消，也不能把综合平均分解释为通过概率。

## 重点诊断

- 高方法论、低落地：决策逻辑或行动细节低于3分。
- 有经验、说不出来：真实性和结果高，但直接性、表达效率低。
- 准备不足：业务相关性与迁移价值低。
- 套话风险：所有答案结构相同，缺少真实细节和取舍。
- 归因风险：结果很好，但本人职责、团队贡献或外部变量说不清。
- 稳定性风险：离职、空窗、创业和回归职场的时间线或因果互相冲突。
- 硬技能风险：用“数据思维”“学习能力”回避SQL、外语、管理等明确要求。
