# 完整工作流

## 目录

1. 证据准备
2. 岗位与风险建模
3. 面试前
4. 模拟面试
5. 面试后
6. 多场迭代

## 1. 证据准备

### 1.1 建立事实底稿

整理候选人的经历、项目、数据、角色边界、失败案例和职业变化。每一项标注：已核验、待确认、不可公开。建立统一时间线，避免离职、空窗、创业和回归职场在不同答案中产生矛盾。

每个核心项目制作证据卡，补齐目标来源、指标口径、本人贡献、取舍、资源依赖、负面结果和归因。

## 2. 岗位与风险建模

### 2.1 拆解岗位

把 JD 转换成五层：

1. 业务为什么招人。
2. 入职后要解决什么问题。
3. 用哪些指标判断成功。
4. 需要什么经历作为证据。
5. 候选人可能在哪些地方被质疑。

### 2.2 建立匹配矩阵

每条岗位要求对应：真实案例、行动细节、量化结果、缺失证据、补救方式。没有证据就标空，不用泛泛的「学习能力强」填补。

### 2.3 审计硬门槛

把工具、年限、行业、管理、语言和地点等门槛分为已证明、相邻能力、明确不具备。明确不具备项单列淘汰风险和诚实应答策略。

### 2.4 建立风险地图

识别经历异常点、显著标签、失败案例、组织边界和隐性管理要求。每个风险点生成至少三层追问。

## 3. 面试前

### 2.1 预测问题

准备比例默认是70%训练时间与追问深度用于过往经历和风险、30%用于岗位和业务。重点不是题目数量，而是命中以下四类：

- 招聘方必须确认的硬能力。
- 候选人最强的证据。
- 候选人最明显的风险。
- 该业务当前最现实的问题。

### 3.2 打磨回答

一个答案只解决一个核心问题。开头15秒先给结论，随后用事实支撑。删掉自我设问、过长铺垫、免责声明和连续模糊词。

同一答案训练15秒、60秒和180秒版本。结构只服务于备课，口头表达必须能自然切换。

### 3.3 做业务功课

最低输出：业务链路、用户、商业目标、核心指标、主要动作、竞品差异、一个独立判断、一个可验证建议。

公司信息缺失时先完成通用业务假设并列出待查清单；不得把假设写成该公司的事实。

### 3.4 做现场预检

检查音频、视频、网络、备用设备、JD、轮次、三张项目证据卡、风险卡、反问卡和保密边界。

## 4. 模拟面试

按真实轮次模拟：HR面关注动机、稳定性和基本匹配；业务面关注项目、判断和落地；终面关注复杂问题、组织协同和长期价值。

一次只问一个问题。追问优先攻击回答中的空白、矛盾和未经证明的结论。

每5题生成一次阶段反馈，但不要中断真实感。

至少包含：一轮硬门槛压力测试、一轮显著风险连续追问、一次随机打断和一个失败案例。没有用户实时回答时，只生成训练计划并标记“未执行”，不伪造模拟结果。

## 5. 面试后

### 5.1 校正来源与角色

先判断材料是真实逐字稿、AI会议纪要还是面试准备稿；确认面试官与候选人说话人。排除设备沟通、候选人自问、面试官业务介绍和重复转写。问题数量标为“确认问题”或“疑似问题”，不能混用。

### 5.2 还原事实

列出全部问题、回答、追问、打断、面试官提供的信息和候选人反问。禁止先下结论再挑证据。

### 5.3 判断关键问题

把问题分成：决定性、重要、一般、噪声。给权重时说明理由，不做伪精确计算。

### 5.4 估计结果

输出区间而非单点：

```text
通过可能性：中等，约40%—60%
置信度：低/中/高
主要正向证据：...
主要负向证据：...
无法观察的变量：同批候选人、HC、内部调整、面试官偏好
```

### 5.5 改写关键答案

只优先修正影响最大的3—5个回答。每个回答给：原问题、原回答问题、证据缺口、优化结构、口语版答案、可能追问。

### 5.6 回写现场情报

记录面试官透露的目标、组织、资源、隐性门槛和下一轮重点。每个反问标明验证的假设及答案带来的判断变化。

## 6. 多场迭代

累计真实结果后校准模型：哪些信号过去被高估，哪些问题反复出现，哪些答案在不同公司有效，哪些公司文化要求不同。

用“涉及场次数”而不是关键词次数统计高频模式。最终形成个人版资产：高频问题库、项目证据卡、风险叙事库、失败案例库、业务研究模板、现场情报和面试结果校准表。

校准表保留面试前区间、置信度、实际结果、真实反馈、高估或低估的信号、不可控变量和下一场是否复现。

## 双模型独立复核

需要复核时执行：

1. 给模型A和模型B相同的脱敏材料与评分标准。
2. 不向模型B提供模型A的结论，避免锚定。
3. 两边分别输出事实、推断、未知、反证和概率区间。
4. 汇总共同证据与冲突证据，不比较谁的措辞更有说服力。
5. 用真实面试结果回写校准记录，检查哪个判断维度长期偏高或偏低。
