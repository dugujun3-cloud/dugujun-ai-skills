# AI 杠杆与个人运营系统

## 先删除，再优化，再自动化

对每项任务依次问：

1. 这件事是否服务当前阶段的主目标？否则停止。
2. 流程和输入是否稳定？否则先手工跑通。
3. 规则是否明确、输出能否验收？否则只让 AI 辅助。
4. 出错是否可逆，是否涉及金钱、权限、公开发布、客户关系或法律责任？高风险必须人工批准。
5. 这项任务是否在锻炼创始人的核心判断？至少先由本人定义方法和质量标准。

## 任务分配

| 类型 | 适合任务 | 边界 |
|---|---|---|
| 删除 | 低价值、无用户结果、重复汇报 | 不因已投入时间继续 |
| AI/脚本 | 整理、分类、初稿、格式、重复执行、监控 | 输入稳定、结果可验收、错误可回滚 |
| 人机协作 | 研究、分析、方案比较、个性化交付 | AI 准备，人作判断和复核 |
| 本人负责 | 价值、定位、关键创意、客户承诺、关系、最终发布 | 不把责任外包给模型 |
| 专业支持 | 财税、法律、资质、复杂安全事项 | AI 只准备问题和材料 |

“AI 能生成”不等于“AI 能负责”。

## 最小工作流规格

```text
目标 → 触发 → 输入 → 处理步骤 → 人工决策点 → 输出
→ 验收标准 → 异常升级 → 回退方案 → 日志 → 复盘指标
```

一次只系统化一条高频、低风险、价值明确的流程。先用真实任务测试正常路径和异常路径，再扩大范围。

任何外部发布、客户发送、付款退款、合同签署、账号权限变更、文件删除/覆盖都默认停在人工批准前。不得静默自动执行。

## 创始人产能审计

用时间日志记录任务、耗时、长期价值、本人不可替代性、收入/信任贡献和精力成本。输出：

- 立即停止。
- 批处理或模板化。
- AI/脚本候选。
- 外包候选。
- 必须进入深度工作块的判断、产品和关键关系。

节省出来的时间必须明确再投资到客户理解、产品、交付、判断或休息；否则自动化只会制造更多杂事。

## 决策准备

AI 可清洗数据、整理证据、找异常、生成备选解释和比较方案；用户必须确认数据口径、区分事实与推断、决定权衡并承担后果。相关性不能写成因果，预测不能写成事实。

## 数据与权限

- 最小化输入，匿名化客户资料，不上传凭据和不必要的敏感数据。
- 明确工具条款、数据去向、保留期和访问权限。
- 关键资产备份，记录版本和运行日志。
- 高风险输出设置人工复核、失败保底和回滚。

## 风险预警

风险按影响、概率、可发现性和可逆性排序。阈值基于自己的历史基线和承受力，不照抄文章数字。每项预警绑定证据源、检查频率、责任人、响应和截止时间；红色信号必须人工核实。
