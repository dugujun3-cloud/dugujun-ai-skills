# 知识库来源地图与使用规则

## 只读根目录

默认使用本 Skill 已提炼的 `references/`。若本机配置了源知识库（环境变量 `DUGUJUN_KNOWLEDGE_BASE_ROOT`，其下常见子目录为 `独孤菌一人公司文章/`），只用于追溯用户观点、框架和素材。不得修改、创建、删除、移动任何知识库文件。只有需要原文语境、用户明确要求依据或现有 reference 不足时，才打开最少量对应文件。

## 来源治理

- 文章是用户知识资产和观点素材，不自动等于外部事实库。
- 案例和数字标记为 `self_reported`、`illustrative`、`unverified` 或 `verified`；没有一手证据时不得升级。
- 带年份的趋势、平台规则、工具能力、价格、法律和税务主张必须实时核验权威来源。
- 文章中引用的第三方人物观点需要原始来源才能直接归因；找不到时改写为一般启发式。
- 不把示例人数、周期、收入倍数、价位、转化率或毛利率固化为普适阈值。
- 索引自称 106 篇，但当前目录盘点为 107 个 Markdown 文件；案例目录与索引列举也有缺口，因此索引仅用于路由，不作为完整性证明。
