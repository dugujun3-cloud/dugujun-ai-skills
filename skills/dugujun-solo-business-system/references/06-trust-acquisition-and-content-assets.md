# 信任、获客与内容资产

## 先定位断点

```text
发现 → 理解 → 相信 → 行动 → 获得结果 → 复购/推荐
```

分别记录每环节证据，不把阅读、粉丝或私域人数自动等同线索和收入。

## 三类信任

- 认知信任：用户理解你的判断和立场。
- 专业信任：方法、过程、案例和交付证明你能做成。
- 人格/关系信任：边界一致、真实互动、承诺兑现和长期稳定。

内容可分为判断、方法、案例/复盘和关系互动。每项内容应回答服务哪个客户问题、建立哪类信任、引导什么下一步，而不是只追求发布频率。

## 内容是否为资产

用三问过滤：

1. 核心判断经过时间后是否仍有价值，或能否低成本更新？
2. 能否转成课程模块、模板、案例、短内容、销售材料或产品功能？
3. 是否强化用户对你能力和产品的认知，而非只依赖一次平台推荐？

优先积累：原创判断、可执行方法、真实案例与失败复盘、客户语言、模板、数据和品牌叙事。弱资产包括无个人判断的综述、纯热点、为日更凑数和未经验证的 AI 批量内容。

## 渠道选择

选择一个主渠道和一个承接点，比较：目标客户密度、问题表达形态、内容优势、触达成本、反馈速度、商业承接、平台风险和可迁移性。

当前平台规则和趋势必须调用实时数据或相应平台 Skill 复核。本 Skill 只决定商业角色和资源分配：

- 小红书执行路由 `dugujun-xhs-operating-workflow` / `dugujun-xiaohongshu`。
- 知乎写作与问答路由 `dugujun-zhihu-writing` / `dugujun-zhihu-answer`。
- 公众号文章到跨平台资产路由现有文章工作流。

不要用本 Skill 直接生成平台成品或绕开平台质量闸门。

## 客户见证

使用 PSR 结构：具体问题 `Problem` → 实际方案 `Solution` → 可验证结果 `Result`。同时保存原始反馈、时间、产品版本、是否匿名和授权范围。

- AI 可以分类、提炼和脱敏，不能补写客户没说过的结果或数字。
- “老师很好、内容丰富”只能证明满意表达，不能证明结果。
- 把见证反向用于检查：产品是否能稳定产生结果，而不只是营销素材。

## 获客实验

每轮明确客户、问题、内容/触达、承接、下一步行为、成本、成熟窗口和停止条件。优先观察线索质量、预约、付款、结果和推荐，不只看曝光。

出现“有流量无成交”时，依次查：人群匹配、问题优先级、offer 清晰度、证据、承接和交付风险；不要直接增加发布量。
