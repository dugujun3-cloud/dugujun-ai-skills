# 专家经验 → 单文件工具 · 共创方法论

把一个人的领域方法论变成一个活的工具。核心认知：**工具的资产是专家的规则库，不是代码。代码是最不值钱的部分，别在需求没对焦前写一行。**

## 何时不用这个 skill

- 需要账号体系、服务端存储、多人协作 → 超出单文件边界，先砍需求
- 用户只想展示内容（方法论文章化）→ 那不是工具，别做
- 需要实时接大模型生成 → 默认拒绝（边际成本+后端复杂度），替代方案见「深度 Prompt 位」

## 阶段 0：形态判断（先于一切）

三种形态，判断标准是**目标用户手里有没有干净数据**：

| 形态 | 适合 | 风险 |
|---|---|---|
| 问答驱动生成方案（默认推荐） | 大多数情况 | 规则库浅则像算命 |
| 真实数据算结果 | 用户手里有规范数据且样本能支撑 | 格式混乱、小样本误结论 |
| 模板库/知识库 | 内容深但交互弱 | 不是产品是文章，产品感最弱 |

拿不准时把三形态成本/效果/传播性摊开给用户选。差异化必须来自「答完题拿到属于自己的方案」，不是内容更多。

## 阶段 1：需求对焦（逐题深问）

一次只问一题，每题给「参考答法」降低回答成本。每组答案先回读再进下一题：确认理解 + 指出答案内部的张力（太宽的人群、矛盾的目标）。题库在 `references/interview-bank.md`，四组：人群与场景 / 方法论内核 / 产出物与体验 / 边界。

必挖的三个点：
1. **触发时刻**：用户打开工具的那个瞬间在愁什么（决定欢迎语和第一屏）
2. **亲手案例**：创造者自己怎么做这件事的（规则库的灵魂素材）
3. **最蠢做法**：创造者最看不惯的错误做法（变成工具里的避坑提示）

产出《需求对焦单》：人群、场景、形态、产出物、边界、商业承接（引流/卖课/获客），用户确认才进下一步。

## 阶段 2：规则库提炼

- 从创造者的存量材料提炼（文章/书稿/课程/聊天记录），每条规则标注来源
- 材料冲突处全部列出，创造者拍板；**场景回答 > 理论材料**
- 需要行业默认值就联网调研，可信度分级（A 官方报告 / B 行业媒体研报 / C 自媒体），找不到就写「未找到」，禁止编数
- 默认值永远标注「经验起点，用你自己的数据校正」

## 阶段 3：功能清单（确认门）

一页清单：页面结构、题库（题干+选项+分支条件）、产出物结构、明确不做清单。用户逐项审完才开发。重点让用户审题库——有没有问错的、漏问的。

## 阶段 4：开发与迭代

技术底座：单文件 HTML + 规则引擎（if/else + 模板组装），不接运行时大模型。边际成本为零、毫秒出方案、纯静态可 surge。

**分支问卷**：题库 12-15 道 + 分支跳题，每人实际答 8-12 道。主干题定分支（行业/模式/目标），分支题收数字。

**反算命三机制**（测评类工具的生死线）：
1. 方案正文引用用户自己填的数字
2. 推理写在策略正文里（不是来源引注，是判断链）
3. 每份方案含否定性建议（「你这种情况不要做什么」——MBTI 从不说你不是谁）

**校验三层**（用户填的每个数都有人把守）：
1. 硬性卡死：范围（占比 0-100、件数 1-20）、占比和 90-110、跨字段矛盾（均值不在价位区间内）
2. 结构异常软提醒：分布倒挂、金字塔倒了，提醒一次，确认无误可二次通过
3. 「没数据，跳过」永远存在，但方案对应位置标注是默认切法

**双向闭合审计**（每次迭代后必做）：
- 正向：每道收集数据的题，答案必须驱动某条策略
- 反向：策略里出现的每个概念，必须有对应题目在收集它

**迭代返工高发点**（本项目实测教训）：
- 不要让用户做抽象判断（「跨度高吗」），收原始数字（最低价/最高价），结论工具算
- 多选默认不限个数
- 标准/档位要写进输入框标签里，不是显示在旁边
- 近义目标合并（扩规模和提复购是一件事的两个名字）
- 时间范围是分布数据的口径，必须有（历史至今/90 天/1 年/2 年）
- 能由上游答案推断的问题就跳过（行业→复购/低频）

**场景矩阵回归**：每个目标 × 行业边界 × 模式 × 有/无数据，20-30 个场景跑 `buildPlan`，查脏文本（undefined/NaN）、策略卡缺件、清单超帽。全绿才交付。

## 阶段 5：交付

- build 脚本合并单文件；外链资源（二维码、logo）base64 内嵌
- logo 用 SVG 直接画：取工具方法论的视觉隐喻（如拐点分布），favicon SVG + PNG 兜底
- surge 整目录部署（整站覆盖，目录里文件必须齐）
- 已有老站时：**同域分路径 > 替换 > 并入模块**。老站加入口横幅导流

## 验收清单

- [ ] 对焦单、功能清单、规则库三份档案齐
- [ ] 双向闭合审计通过
- [ ] 场景矩阵回归全绿
- [ ] 校验三层实测（瞎填被卡、软提醒可过）
- [ ] 单文件无外部依赖，线上 200
- [ ] 商业承接位（CTA）可用
