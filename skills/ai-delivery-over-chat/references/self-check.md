# 两分钟自检表

给用户快速自测，或诊断前先让用户勾选。

## A. 场景（必填一句）

最近一次：我用 AI 做 ______，花了大约 ______，最后交差的是（我 / AI / 混搭拼出来的）。

## B. 三关勾选（是=命中）

**半成品**

- [ ] AI 给的东西「看起来像」，但不能直接交差
- [ ] 我大量时间花在整理、对齐口径、拼装
- [ ] 忙完发现活并没有少，只是前半截更热闹

**越聊越亏**

- [ ] 纠正超过 3 轮，口径仍在飘
- [ ] 改完一处，另一处错法换皮出现
- [ ] 事后觉得自己做可能更早收工

**换了白换**

- [ ] 近 30 天换过聊天入口/App，但交付方式没变
- [ ] 新工具仍是「我粘贴 → 它回复 → 我验收拼装」
- [ ] 没有固定规矩文件 / 连续任务链

## C. 两轴（各选一）

模型能力：□ 明显不够 □ 够用但没用上 □ 不清楚  
是否离开纯聊天：□ 纯聊天框 □ 有连续步骤/读文件/改到过线 □ 不清楚

## D. 速判

- 半成品或越聊越亏 ≥ 2 项 → **优先改用法与交付定义**
- 换了白换 ≥ 2 项 → **禁止再换皮，先定能交标准**
- 模型明显不够 + 已有连续干活需求 → **再谈换模型/换连续干活工具**
