# 一人公司经营复盘

一人公司最容易跳过的一件事就是复盘——没有同事催，没有周会，数字散在脑子里。

本 Skill 把复盘做成一个**固定节奏、可重复执行**的动作：对比指标、回看决策、给出下周期候选动作。

## 定位

经营系统的「复盘」阶段执行器。上游主控决定做什么、卖什么；本 Skill 只负责**结构、对比、决策回看**，产出复盘报告交回主控验收。

## 何时使用

- 固定节奏到了（每周／每月），需要出一份复盘
- 说「接着上次的复盘」，需要续着上期往下做

## 何时不用

- 目标不是自己的经营项目 → 不接管
- 需要从外部系统自动取数 → 不做，数字靠本人反馈
- 经营决策本身 → 只出候选动作，决策归本人

## 输入

| 来源 | 内容 |
| --- | --- |
| 项目状态文件 | 当前阶段、目标、已完成项 |
| 决策记录 | 之前立过项的长期决策及其状态（如有） |
| 上期复盘 | 最近一期复盘报告，作对比基准 |
| 本期数字 | **本人提供**——口述或贴文件，按下方模板列出 |

## 流程

1. **定位项目**。多个候选时列出状态差异让用户选，不自行假设。
2. **拉对比基准**。上期复盘 + 当前状态文件。
3. **数字填空**。按模板列出各条线应填的数字，用户口述或贴文件。信息不足时**最多集中提 3 个会改变决策的问题**，不逐项追问。
4. **对比**。本期 vs 上期 vs 目标，三个维度都要有，缺哪个就标明缺哪个。
5. **决策回看**。上期的候选动作执行了没有、效果如何——对照状态记录与本人反馈，不靠记忆下结论。
6. **产出复盘报告**。
7. **交回主控**。报告路径 + 自检结果 + 未解决问题；**状态更新由上游主控执行，本 Skill 不越权改主控状态文件**。

## 数字模板

让用户填空而不是让他自己想「该报什么」：

```text
本期区间：____ 至 ____

收入线：本期 ____ / 上期 ____ / 目标 ____
客户线：新增 ____ / 流失 ____ / 在跟 ____
内容线：产出 ____ 篇 / 主要平台 ____
产品线：在售 ____ / 在研 ____ / 本期交付 ____

本期最大的意外：____
本期最想放弃的一件事：____
```

## 复盘报告结构

- **指标对比**：本期 / 上期 / 目标，差异与可能原因
- **决策回看**：上期候选动作的执行情况与效果
- **风险点**：正在积累但还没爆的问题
- **下周期 3-5 个候选动作**：每个都要写清动作、预计投入、预期回报
- **停止 / 调整 / 继续**建议：对当前在跑的线给明确判断

## 输出契约

- 复盘报告（必交）
- 对话摘要：下周期前 3 个候选动作 + 停止／调整／继续建议
- **不产出**：经营决策、对外报告、任何外部系统产物

## 边界

- 不自动取数；数字靠本人反馈
- **只出候选动作，不做经营决策**——决策与真实商业动作归本人
- 不改上游主控的状态文件（交回主控更新）
- 不因为「顺手」把复盘结论直接发布或外发

## 验收

用真实一周数据跑一轮：指标对比正确、决策回看有依据、候选动作可执行、上游状态未被越权修改。
