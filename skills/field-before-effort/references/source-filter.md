# 源帖过滤

源：https://x.com/zengying1107/status/2099367336977596816

## 采用（顺序，不是人物）

- 舍小取大；不确定里找可验证的更优解。
- 注意力是能量：别把日历花在不能改变结果的小事上。
- 判断「结果发生的场」先于死磕个体能力。
- 先改环境（合法换池），再匠人。
- 对已证伪的路果断停，不是表演坚持。

## 丢掉

- 枭雄叙事、加密梭哈、用他人当流量和人脉道具。
- 「孙学是自私的、坑别人也多一点」。
- 性别对立的择偶地理决定论（当通用人生解）。
- 宿命论、被上天选中、刘邦/追穷寇当操作系统。
- 任何违法或灰产路径。

提纯句：努力决定下限；你站的场决定这轮努力有没有上限。场必须合法、可踏进、两周能验证。
