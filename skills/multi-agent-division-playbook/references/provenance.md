# 来源说明

本 Skill 是从作者本人**实际运行中的多 Agent 协作规则**提炼而成，来源包括三类内部文档：

1. 分工矩阵（哪个域由哪个端主控、产物命名空间如何划分）
2. 意图路由规则（否定语优先、域判定优先、高风险动作确认等优先级）
3. 跨端综合规则（输出风格共识、状态与验收口径、质量闸门）

## 提炼时做了什么

- **具体工具名 → 语义槽位**：原文里的产品名全部替换为「写作端 / 工程端 / 检索端」这类角色，因为工具会换、职责不会
- **私有路径 → 抽象命名空间**：所有本机路径改为 `<命名空间>` 占位
- **私有业务规则 → 删除**：与协作协议无关的业务方法论（内容平台标准、行业判断等）不在本 Skill 范围内
- **新增**：第三节「范围声明」与第五节「只读 / 可写清单」是提炼过程中总结出的通用部分，原文分散在多处

## 为什么标为 distillation 而非 mirror

本 Skill 不对应任何一个本地文件，因此无法用「文件级同步」维护。上游规则演进时，需要**重新提炼**而不是复制。对应用户侧 manifest 的 `source_status` 需要按此理解。
